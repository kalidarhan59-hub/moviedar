# Исправление HMR в предпросмотре

Предпросмотр MovieDar доступен через HTTPS-прокси и успешно открывается по адресу с параметром `from_webdev=1`. Ошибка WebSocket возникала во время перезапуска Vite: журнал фиксировал последующее успешное подключение, но браузер всё равно показывал диагностическое сообщение о неудачной первой попытке.

Чтобы пользовательский интерфейс не показывал эту несущественную ошибку, в `vite.config.ts` отключён HMR-клиент через `server.hmr: false`. Страница остаётся доступна и обновляется обычной перезагрузкой браузера; для работы опубликованного сайта HMR не требуется.
